| | pH | PCO2 | HCO3⁻ |

**Must-knows:**
- Cell regeneration hierarchy: Labile > Stable > Permanent (cardiac muscle = LEAST regenerative; smooth muscle is stable, NOT permanent — repeated trap).
- Cell cycle: G0→G1→S→G2→M.
- Cell injury mechanisms: mitochondrial damage, membrane leakage, Ca²⁺ derangement, lysosomal enzyme leak — "normal protein synthesis" always the false option.
- Reversible injury: fatty change. Irreversible: pyknosis, karyolysis, karyorrhexis.
- Cardiac injury marker: Creatine kinase (CK-MB).
- Adaptations: Hypertrophy/Hyperplasia, Atrophy, Metaplasia (e.g. bronchial columnar→squamous in smokers).
- Discoverer of phagocytosis: Elie Metchnikoff.
- Chediak-Higashi syndrome: impairs phagolysosome formation.
- Worst outcome of thrombus: detachment (→embolism).
- Inflammation mediators: histamine/serotonin (mast cells); bradykinin (pain, vasodilation, smooth muscle contraction — NOT opsonization).
- Diapedesis = WBC migration through endothelial junctions.
- Main inflammatory cell, ACUTE = neutrophil; CHRONIC = macrophage.
- Granuloma = necrosis + epithelioid cells + giant cells + lymphocytes (TB, sarcoidosis, schistosomiasis — NOT asthma).
- Exudate (high protein, inflammatory) vs Transudate (low protein, ↓oncotic/↑hydrostatic pressure).
- Oedema: commonest cause = ↓plasma oncotic pressure (liver cirrhosis); potassium retention is NOT a cause.
- Wound healing: first event = blood clot; granulation tissue = fibroblasts+macrophages+new capillaries.
- Wound complications: dehiscence, keloid/hypertrophic scar, proud flesh, contracture.
- Neoplasia: p53/RB = tumour suppressors; c-Myc/RAS/BCR = oncogenes; HPV/EBV/HepB oncogenic (Polio is NOT); Burkitt's = B-lymphocyte proliferation; immune defense = cytotoxic T/NK/macrophages; Grading=differentiation, Staging=spread (TNM).
- ABG reading practice: pH<7.35 + HCO3<22 + PCO2 normal → metabolic acidosis.

**Must-knows (Histopathology/Cytopathology techniques):**
- Recommended microtome section thickness: **5 micrometers** (not 3 or 5mm).
- Haematoxylin: basic stain, stains acidic components (nucleic acids) blue, stains nuclei.
- Ischaemic time = time from surgery to specimen placed in fixative.
- Bone decalcification endpoint confirmed by: X-ray method.
- Gold standard for TB bacilli: Ziehl-Neelsen stain.
- Fixative volume: 15–20× tissue volume.
- DPX = hydrophobic adhesive mountant.
- Dehydration = increasing grades of ethanol.
- Clearing agents: xylene, chloroform, benzene (paraffin wax is NOT a clearing agent — it's the embedding medium).
- "Rush diagnosis" = priority for critically-ill patient specimens.
- Special stains: Congo red→amyloid; Ziehl-Neelsen→AFB/TB; Grocott methenamine silver→fungi; Von Kossa→calcium; Prussian blue→iron; Verhoeff-van Gieson→elastic fibers.
- IHC uses: tumour origin ID, receptor status (HER2/ER), infectious agent ID, prognostic markers.
- Bethesda categories: ASC-US, ASC-H, LSIL, HSIL, AGC.
- Chronologically: fixation → gross exam/cut-up → processing (dehydration→clearing→wax infiltration) → embedding → microtome sectioning → mounting on slides → staining → coverslipping → pathologist review.
