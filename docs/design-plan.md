# Ompath Study design plan

One rule: **text flows, nothing sits in a box.** Space and type do the work.

1. **Type first.** Large serif headings, 17-19px body, 68-character lines, a slightly larger opening paragraph in each section. No cards, borders or colour bars around reading text.
2. **One accent.** Teal for the single main action on a page. Everything else is text or a quiet outline button.
3. **Motion that is calm.** A slow colour wash behind the opening block of a page, nothing else moves on its own. Respect "reduce motion".
4. **Buttons.** 48px high, pill shaped, an icon and a short label. One filled button per row at most.
5. **Overlays.** Quick-read panels open instantly with what is already known, fill in as more arrives, close with Back or a pull down.
6. **Every page loads something real at once.** No page shows only placeholders: the site's own content first, the rest slots in.
7. **Monitoring.** `.github/workflows/site-audit.yml` opens real pages after every deploy and every morning and fails (you get an e-mail) if one is broken.

Rollout order: topic pages (done), quick-read panel (done), blog and note pages, year pages, home, flashcards and exams.
